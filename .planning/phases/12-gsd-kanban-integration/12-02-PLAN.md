# Plan 12-02: GSD → Kanban 연동 (Phase별 Task 그룹화)

## Objective

GSD에서 생성된 ROADMAP.md의 Phase/Plan 구조를 Kanban 보드에 Task로 표시한다. Phase별로 Task를 그룹화하고, 각 Plan을 실행 가능한 Task로 변환한다.

### Task 2: ROADMAP → Task 변환 서비스 구현
**File**: `apps/frontend/src/main/gsd-service.ts`

`convertRoadmapToTasks()` 메서드 추가:

```typescript
interface GsdTaskConversionResult {
  tasks: ConvertedTask[];
  phases: PhaseGroup[];
}

interface ConvertedTask {
  id: string;           // "gsd-{phase}-{plan}" (예: "gsd-01-02")
  title: string;        // Plan 이름
  description: string;  // Plan 목표
  phaseNumber: number;
  planNumber: number;
  status: 'pending' | 'in_progress' | 'complete';
  parallelSafe: boolean;
  dependsOn: string[];
}

interface PhaseGroup {
  id: string;           // "gsd-phase-{n}"
  name: string;         // "Phase {n}: {title}"
  phaseNumber: number;
  tasks: string[];      // Task IDs
  completed: boolean;
}

async convertRoadmapToTasks(projectPath: string): Promise<GsdTaskConversionResult> {
  const roadmapPath = path.join(projectPath, '.planning', 'ROADMAP.md');
  const content = await fs.readFile(roadmapPath, 'utf-8');

  // Parse ROADMAP.md
  const phases = this.parsePhases(content);
  const plans = this.parsePlans(content);

  // Convert to tasks
  const tasks: ConvertedTask[] = [];
  const phaseGroups: PhaseGroup[] = [];

  for (const phase of phases) {
    const phaseTasks = plans
      .filter(p => p.phaseNumber === phase.number)
      .map(plan => ({
        id: `gsd-${plan.id}`,
        title: plan.name,
        description: plan.goal || '',
        phaseNumber: phase.number,
        planNumber: plan.planNumber,
        status: plan.completed ? 'complete' : 'pending',
        parallelSafe: plan.parallelSafe ?? true,
        dependsOn: plan.dependsOn || []
      }));

    tasks.push(...phaseTasks);

    phaseGroups.push({
      id: `gsd-phase-${phase.number}`,
      name: `Phase ${phase.number}: ${phase.title}`,
      phaseNumber: phase.number,
      tasks: phaseTasks.map(t => t.id),
      completed: phaseTasks.every(t => t.status === 'complete')
    });
  }

  return { tasks, phases: phaseGroups };
}
```

**Acceptance**: ROADMAP 파싱 및 Task 변환 동작
