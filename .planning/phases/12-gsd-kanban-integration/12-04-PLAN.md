# Plan 12-04: 병렬 실행 및 의존성 관리

## Objective

`parallel_safe: true`인 GSD Task들을 **병렬로 실행**하고, `depends_on` 의존성을 검사하여 안전한 실행 순서를 보장한다. 에이전트 터미널에서 여러 Task가 동시에 실행되는 것을 시각화한다.

## Context

### PLAN.md Frontmatter
```yaml
---
phase: 3
plan: 1
name: Setup Database
parallel_safe: true    # 다른 plan과 병렬 실행 가능
depends_on: []         # 의존성 없음
---
```

```yaml
---
phase: 3
plan: 2
name: Setup API
parallel_safe: true
depends_on: [03-01]    # 03-01 완료 후 실행 가능
---
```

### 병렬 실행 규칙
1. `parallel_safe: false` → 항상 순차 실행
2. `parallel_safe: true` + `depends_on: []` → 즉시 병렬 실행 가능
3. `parallel_safe: true` + `depends_on: [X]` → X 완료 후 병렬 실행 가능
4. 동일 Phase 내 병렬 실행 우선 (Phase 간은 순차)

### Task 1: 의존성 그래프 분석 서비스
**File**: `apps/frontend/src/main/gsd-dependency-analyzer.ts` (신규)

의존성 분석 및 실행 순서 결정:

```typescript
interface TaskNode {
  id: string;           // Plan ID (예: "03-01")
  parallelSafe: boolean;
  dependsOn: string[];
  status: 'pending' | 'ready' | 'running' | 'complete' | 'blocked';
  blockedBy?: string[]; // 아직 완료되지 않은 의존성
}

interface ExecutionPlan {
  phases: ExecutionPhase[];
  totalTasks: number;
  parallelizable: number;
}

interface ExecutionPhase {
  phaseNumber: number;
  waves: ExecutionWave[];  // 각 wave는 병렬 실행 가능한 Task 그룹
}

interface ExecutionWave {
  waveNumber: number;
  tasks: string[];         // 동시 실행 가능한 Task ID 목록
}

export class GsdDependencyAnalyzer {
  /**
   * ROADMAP.md에서 실행 계획 생성
   */
  async analyzeExecutionPlan(projectPath: string): Promise<ExecutionPlan> {
    const tasks = await this.loadTaskNodes(projectPath);
    const phases = this.groupByPhase(tasks);

    return {
      phases: phases.map(phase => ({
        phaseNumber: phase.number,
        waves: this.calculateWaves(phase.tasks)
      })),
      totalTasks: tasks.length,
      parallelizable: tasks.filter(t => t.parallelSafe).length
    };
  }

  /**
   * Wave 계산: 의존성 기반 병렬 실행 그룹 분리
   */
  private calculateWaves(tasks: TaskNode[]): ExecutionWave[] {
    const waves: ExecutionWave[] = [];
    const completed = new Set<string>();
    let remaining = [...tasks];
    let waveNumber = 1;

    while (remaining.length > 0) {
      // 현재 wave에서 실행 가능한 Task 찾기
      const ready = remaining.filter(t =>
        t.dependsOn.every(dep => completed.has(dep))
      );

      if (ready.length === 0) {
        throw new Error('Circular dependency detected');
      }

      // parallel_safe인 것들은 하나의 wave에 모두 포함
      const parallelTasks = ready.filter(t => t.parallelSafe);
      const sequentialTasks = ready.filter(t => !t.parallelSafe);

      if (parallelTasks.length > 0) {
        waves.push({
          waveNumber: waveNumber++,
          tasks: parallelTasks.map(t => t.id)
        });
        parallelTasks.forEach(t => completed.add(t.id));
        remaining = remaining.filter(t => !parallelTasks.includes(t));
      }

      // Sequential tasks는 각각 별도 wave
      for (const task of sequentialTasks) {
        waves.push({
          waveNumber: waveNumber++,
          tasks: [task.id]
        });
        completed.add(task.id);
        remaining = remaining.filter(t => t.id !== task.id);
      }
    }

    return waves;
  }

  /**
   * 특정 Task가 실행 가능한지 확인
   */
  canExecute(taskId: string, completedTasks: Set<string>, tasks: TaskNode[]): boolean {
    const task = tasks.find(t => t.id === taskId);
    if (!task) return false;
    return task.dependsOn.every(dep => completedTasks.has(dep));
  }
}
```

**Acceptance**: 의존성 분석, Wave 계산, 순환 의존성 감지

### Task 2: ParallelExecutionManager 구현
**File**: `apps/frontend/src/main/gsd-parallel-executor.ts` (신규)

병렬 실행 관리자:

```typescript
interface ExecutionSession {
  sessionId: string;
  taskId: string;
  process: ChildProcess;
  status: 'running' | 'complete' | 'error';
  output: string;
  startedAt: Date;
}

export class GsdParallelExecutor {
  private sessions: Map<string, ExecutionSession> = new Map();
  private maxParallel: number = 3;  // 동시 실행 최대 개수

  /**
   * Phase 전체 병렬 실행
   */
  async executePhaseParallel(
    projectPath: string,
    phaseNumber: number,
    onProgress: (updates: TaskProgress[]) => void
  ): Promise<PhaseExecutionResult> {
    const analyzer = new GsdDependencyAnalyzer();
    const plan = await analyzer.analyzeExecutionPlan(projectPath);
    const phase = plan.phases.find(p => p.phaseNumber === phaseNumber);

    if (!phase) throw new Error(`Phase ${phaseNumber} not found`);

    const completed = new Set<string>();
    const results: TaskExecutionResult[] = [];

    // Wave별 순차 실행 (Wave 내에서는 병렬)
    for (const wave of phase.waves) {
      const waveResults = await this.executeWave(
        projectPath,
        wave.tasks,
        (updates) => onProgress(updates)
      );

      results.push(...waveResults);
      wave.tasks.forEach(id => completed.add(id));
    }

    return {
      phaseNumber,
      totalTasks: results.length,
      successful: results.filter(r => r.success).length,
      failed: results.filter(r => !r.success).length,
      results
    };
  }

  /**
   * Wave 내 Task들 병렬 실행
   */
  private async executeWave(
    projectPath: string,
    taskIds: string[],
    onProgress: (updates: TaskProgress[]) => void
  ): Promise<TaskExecutionResult[]> {
    // maxParallel 제한 적용
    const chunks = this.chunkArray(taskIds, this.maxParallel);
    const results: TaskExecutionResult[] = [];

    for (const chunk of chunks) {
      const chunkResults = await Promise.all(
        chunk.map(taskId => this.executeTask(projectPath, taskId, onProgress))
      );
      results.push(...chunkResults);
    }

    return results;
  }

  /**
   * 개별 Task 실행
   */
  private async executeTask(
    projectPath: string,
    taskId: string,
    onProgress: (updates: TaskProgress[]) => void
  ): Promise<TaskExecutionResult> {
    const sessionId = `${taskId}-${Date.now()}`;
    const planPath = path.join(projectPath, '.planning', 'phases', `${taskId}-PLAN.md`);

    const session: ExecutionSession = {
      sessionId,
      taskId,
      process: null!,
      status: 'running',
      output: '',
      startedAt: new Date()
    };

    this.sessions.set(sessionId, session);

    return new Promise((resolve) => {
      const gsdService = new GsdService();

      gsdService.executePlan(projectPath, planPath, {
        onOutput: (chunk) => {
          session.output += chunk;
          onProgress([{
            taskId,
            sessionId,
            status: 'running',
            output: chunk,
            progress: this.parseProgress(session.output)
          }]);
        },
        onComplete: (result) => {
          session.status = 'complete';
          onProgress([{
            taskId,
            sessionId,
            status: 'complete',
            progress: 100
          }]);
          resolve({ taskId, success: true, output: session.output });
        },
        onError: (error) => {
          session.status = 'error';
          onProgress([{
            taskId,
            sessionId,
            status: 'error',
            error
          }]);
          resolve({ taskId, success: false, error, output: session.output });
        }
      });
    });
  }

  /**
   * 실행 중인 세션 취소
   */
  cancelAll(): void {
    for (const session of this.sessions.values()) {
      if (session.status === 'running' && session.process) {
        session.process.kill();
      }
    }
    this.sessions.clear();
  }
}
```

**Acceptance**: 병렬 실행, 진행률 콜백, 취소 기능

```tsx
export function ParallelExecutionDashboard({
  projectPath,
  phaseNumber,
  onClose
}: ParallelExecutionDashboardProps) {
  const [executionPlan, setExecutionPlan] = useState<ExecutionPlan | null>(null);
  const [taskProgress, setTaskProgress] = useState<Map<string, TaskProgress>>(new Map());
  const [isRunning, setIsRunning] = useState(false);

  // 실행 계획 로드
  useEffect(() => {
    window.electronAPI.gsd.getExecutionPlan(projectPath, phaseNumber)
      .then(plan => setExecutionPlan(plan));
  }, [projectPath, phaseNumber]);

  // 진행률 이벤트 리스너
  useEffect(() => {
    return window.electronAPI.gsd.onParallelProgress((updates) => {
      setTaskProgress(prev => {
        const next = new Map(prev);
        updates.forEach(u => next.set(u.taskId, u));
        return next;
      });
    });
  }, []);

  const handleStartAll = async () => {
    setIsRunning(true);
    await window.electronAPI.gsd.executePhaseParallel(projectPath, phaseNumber);
    setIsRunning(false);
  };

  const handleCancel = () => {
    window.electronAPI.gsd.cancelParallelExecution();
    setIsRunning(false);
  };

  const runningTasks = Array.from(taskProgress.values())
    .filter(t => t.status === 'running');

  return (
    <Dialog open onOpenChange={() => !isRunning && onClose()}>
      <DialogContent className="max-w-4xl h-[700px] flex flex-col">
        <DialogHeader>
          <DialogTitle>
            Phase {phaseNumber} 병렬 실행
          </DialogTitle>
          <DialogDescription>
            {executionPlan?.parallelizable}/{executionPlan?.totalTasks} tasks can run in parallel
          </DialogDescription>
        </DialogHeader>

        {/* Task 목록 */}
        <div className="space-y-2 py-4">
          {executionPlan?.phases[0]?.waves.map((wave, i) => (
            <div key={i} className="border rounded-lg p-3">
              <div className="text-sm text-muted-foreground mb-2">
                Wave {wave.waveNumber}
                {wave.tasks.length > 1 && (
                  <Badge variant="outline" className="ml-2">
                    <Zap className="h-3 w-3 mr-1" />
                    {wave.tasks.length} parallel
                  </Badge>
                )}
              </div>
              <div className="grid grid-cols-3 gap-2">
                {wave.tasks.map(taskId => {
                  const progress = taskProgress.get(taskId);
                  return (
                    <TaskProgressCard
                      key={taskId}
                      taskId={taskId}
                      progress={progress}
                    />
                  );
                })}
              </div>
            </div>
          ))}
        </div>

        {/* 실행 중 터미널 그리드 */}
        {runningTasks.length > 0 && (
          <div className="flex-1 overflow-hidden">
            <div className="text-sm font-medium mb-2">
              Running ({runningTasks.length} parallel)
            </div>
            <div className={cn(
              "grid gap-2 h-full",
              runningTasks.length === 1 && "grid-cols-1",
              runningTasks.length === 2 && "grid-cols-2",
              runningTasks.length >= 3 && "grid-cols-3"
            )}>
              {runningTasks.map(task => (
                <div key={task.taskId} className="border rounded-lg overflow-hidden">
                  <div className="bg-muted px-2 py-1 text-xs font-medium">
                    {task.taskId}
                    <Progress value={task.progress} className="h-1 mt-1" />
                  </div>
                  <TerminalOutput
                    output={task.output || ''}
                    isRunning={task.status === 'running'}
                    className="h-[200px]"
                  />
                </div>
              ))}
            </div>
          </div>
        )}

        {/* 액션 버튼 */}
        <div className="flex justify-end gap-2 pt-4 border-t">
          {!isRunning ? (
            <>
              <Button variant="outline" onClick={onClose}>
                Close
              </Button>
              <Button onClick={handleStartAll}>
                <Play className="h-4 w-4 mr-1" />
                Execute All
              </Button>
            </>
          ) : (
            <Button variant="destructive" onClick={handleCancel}>
              <Square className="h-4 w-4 mr-1" />
              Cancel
            </Button>
          )}
        </div>
      </DialogContent>
    </Dialog>
  );
}
```

**Acceptance**: Wave 표시, 병렬 터미널 그리드, 진행률 업데이트

```typescript
ipcMain.handle('GSD_GET_EXECUTION_PLAN', async (event, projectPath: string, phaseNumber: number) => {
  const analyzer = new GsdDependencyAnalyzer();
  const plan = await analyzer.analyzeExecutionPlan(projectPath);
  return plan.phases.find(p => p.phaseNumber === phaseNumber) || null;
});

ipcMain.handle('GSD_EXECUTE_PHASE_PARALLEL', async (event, projectPath: string, phaseNumber: number) => {
  const executor = new GsdParallelExecutor();

  return executor.executePhaseParallel(projectPath, phaseNumber, (updates) => {
    event.sender.send('gsd:parallel:progress', updates);
  });
});

ipcMain.handle('GSD_CANCEL_PARALLEL_EXECUTION', async () => {
  const executor = GsdParallelExecutor.getInstance();
  executor.cancelAll();
  return { success: true };
});
```

```typescript
export const gsdApi = {
  // ... 기존 메서드

  // Parallel Execution
  getExecutionPlan: (projectPath: string, phaseNumber: number) =>
    ipcRenderer.invoke('GSD_GET_EXECUTION_PLAN', projectPath, phaseNumber),

  executePhaseParallel: (projectPath: string, phaseNumber: number) =>
    ipcRenderer.invoke('GSD_EXECUTE_PHASE_PARALLEL', projectPath, phaseNumber),

  cancelParallelExecution: () =>
    ipcRenderer.invoke('GSD_CANCEL_PARALLEL_EXECUTION'),

  onParallelProgress: (callback: (updates: TaskProgress[]) => void) => {
    const handler = (_: unknown, updates: TaskProgress[]) => callback(updates);
    ipcRenderer.on('gsd:parallel:progress', handler);
    return () => ipcRenderer.removeListener('gsd:parallel:progress', handler);
  }
};
```
