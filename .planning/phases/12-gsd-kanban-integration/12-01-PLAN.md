# Plan 12-01: Ideas → GSD 변환 (대화형 Chat UI)

## Objective

Ideas 탭에서 아이디어를 선택하면 **대화형 Chat UI**를 통해 GSD 프로젝트로 변환한다. Claude와 실시간 대화하면서 프로젝트 요구사항을 수집하고, 완료 시 `.planning/` 구조를 자동 생성한다.

## Context

### 현재 상태
- **IdeaCard.tsx**: "Convert to Task" 버튼만 존재 (onConvert 콜백)
- **task-converter.ts**: Idea → `.auto-claude/specs/` 변환 로직
- **GSD 워크플로우**: `/gsd:new-project` → 대화형 질문/답변으로 PROJECT.md 생성

### 목표 UX 흐름
1. IdeaCard에서 "GSD 프로젝트로 변환" 버튼 클릭
2. **GsdChatDialog** 모달 열림 (Chat UI)
3. Claude가 `/gsd:new-project` 실행하며 질문 (목표, 기술 스택, 제약조건 등)
4. 사용자가 대화창에서 답변 입력
5. Claude가 답변 기반으로 추가 질문 또는 요약
6. 대화 완료 시 `.planning/` 디렉토리 구조 생성
7. 아이디어 상태를 'gsd_converted'로 변경

### 참고 파일
- `IdeaCard.tsx` - 버튼 추가 위치 (라인 128-164)
- `task-converter.ts` - 변환 로직 참고
- `gsd-service.ts` - Claude CLI 실행 로직 (Phase 11 구현)
- `CreateRoadmapDialog.tsx` - 스트리밍 UI 참고


### Task 5: GSD Chat API 및 타입 정의
**File**: `apps/frontend/src/preload/gsd-api.ts`

Preload API 확장:

```typescript
// 타입 정의
export interface GsdChatSession {
  sessionId: string;
  projectPath: string;
  status: 'active' | 'complete' | 'error';
}

export interface GsdChatMessage {
  role: 'user' | 'assistant';
  content: string;
  timestamp: string;
}

// API 메서드
export const gsdApi = {
  // ... 기존 메서드

  startChatSession: (projectPath: string, idea: IdeaInput) =>
    ipcRenderer.invoke('GSD_START_CHAT_SESSION', projectPath, idea),

  sendChatMessage: (sessionId: string, message: string) =>
    ipcRenderer.invoke('GSD_SEND_CHAT_MESSAGE', sessionId, message),

  endChatSession: (sessionId: string) =>
    ipcRenderer.invoke('GSD_END_CHAT_SESSION', sessionId),

  // 이벤트 리스너
  onChatMessage: (callback: (chunk: string) => void) => {
    const handler = (_: unknown, chunk: string) => callback(chunk);
    ipcRenderer.on('gsd:chat:message', handler);
    return () => ipcRenderer.removeListener('gsd:chat:message', handler);
  },

  onChatComplete: (callback: (result: { gsdPath: string }) => void) => {
    const handler = (_: unknown, result: { gsdPath: string }) => callback(result);
    ipcRenderer.on('gsd:chat:complete', handler);
    return () => ipcRenderer.removeListener('gsd:chat:complete', handler);
  }
};
```

**Acceptance**: API 타입 정의, preload 노출
