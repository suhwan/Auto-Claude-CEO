# Plan 12-03: Kanban Task 실행 UI (Plan/Research/Execute 버튼)

## Objective

Kanban에서 GSD Task를 클릭하면 상세 패널이 열리고, **Plan / Research / Execute** 3가지 실행 버튼을 제공한다. 각 버튼은 해당 GSD 명령을 실행하고 결과를 터미널 스타일로 표시한다.

## Context

### GSD 실행 명령
- **Plan**: `/gsd:plan-phase {phaseNumber}` - 실행 계획 생성
- **Research**: `/gsd:research-phase {phaseNumber}` - 기술 조사 수행
- **Execute**: `/gsd:execute-plan {planPath}` - 계획 실행

### 목표 UX 흐름
1. Kanban에서 GSD Task 카드 클릭
2. 우측에 Task Detail 패널 슬라이드 아웃
3. Task 정보 + Plan/Research/Execute 버튼 표시
4. 버튼 클릭 → 해당 GSD 명령 실행
5. 실행 출력이 터미널 스타일로 실시간 표시
6. 완료 시 Task 상태 자동 업데이트

```tsx
export function TerminalOutput({ output, isRunning, className }: TerminalOutputProps) {
  const outputRef = useRef<HTMLDivElement>(null);

  // 자동 스크롤
  useEffect(() => {
    if (outputRef.current) {
      outputRef.current.scrollTop = outputRef.current.scrollHeight;
    }
  }, [output]);

  return (
    <div className={cn(
      "bg-zinc-900 text-zinc-100 rounded-lg p-4 font-mono text-sm h-full overflow-auto",
      className
    )}>
      {/* 터미널 헤더 */}
      <div className="flex items-center gap-2 mb-2 pb-2 border-b border-zinc-700">
        <div className="flex gap-1.5">
          <div className="w-3 h-3 rounded-full bg-red-500" />
          <div className="w-3 h-3 rounded-full bg-yellow-500" />
          <div className="w-3 h-3 rounded-full bg-green-500" />
        </div>
        <span className="text-zinc-400 text-xs">GSD Terminal</span>
        {isRunning && (
          <Loader2 className="h-3 w-3 animate-spin text-primary ml-auto" />
        )}
      </div>

      {/* 출력 내용 */}
      <div ref={outputRef} className="whitespace-pre-wrap">
        {output || (
          <span className="text-zinc-500">
            Select an action above to start...
          </span>
        )}
      </div>

      {/* 실행 중 커서 */}
      {isRunning && (
        <span className="animate-pulse">▋</span>
      )}
    </div>
  );
}
```

### Task 3: GSD Task 실행 IPC 핸들러
**File**: `apps/frontend/src/main/ipc-handlers/gsd-handlers.ts`

Task별 실행 핸들러 추가:

```typescript
// Plan Phase
ipcMain.handle('GSD_PLAN_TASK', async (event, projectPath: string, phaseNumber: number) => {
  const gsdService = new GsdService();
  const command = `/gsd:plan-phase ${phaseNumber}`;

  return gsdService.executeCommand(projectPath, command, {
    onOutput: (chunk) => {
      event.sender.send('gsd:task:output', chunk);
    },
    onComplete: (result) => {
      event.sender.send('gsd:task:complete', result);
    },
    onError: (error) => {
      event.sender.send('gsd:task:error', error);
    }
  });
});

// Research Phase
ipcMain.handle('GSD_RESEARCH_TASK', async (event, projectPath: string, phaseNumber: number) => {
  const gsdService = new GsdService();
  const command = `/gsd:research-phase ${phaseNumber}`;

  return gsdService.executeCommand(projectPath, command, {
    onOutput: (chunk) => event.sender.send('gsd:task:output', chunk),
    onComplete: (result) => event.sender.send('gsd:task:complete', result),
    onError: (error) => event.sender.send('gsd:task:error', error)
  });
});

// Execute Plan
ipcMain.handle('GSD_EXECUTE_TASK', async (event, projectPath: string, planPath: string) => {
  const gsdService = new GsdService();
  const command = `/gsd:execute-plan`;

  return gsdService.executeCommand(projectPath, command, {
    args: [planPath],
    onOutput: (chunk) => event.sender.send('gsd:task:output', chunk),
    onComplete: (result) => event.sender.send('gsd:task:complete', result),
    onError: (error) => event.sender.send('gsd:task:error', error)
  });
});

// Cancel Task
ipcMain.handle('GSD_CANCEL_TASK', async (event, sessionId: string) => {
  const gsdService = new GsdService();
  return gsdService.cancelExecution(sessionId);
});
```

### Task 4: Preload API 확장
**File**: `apps/frontend/src/preload/gsd-api.ts`

Task 실행 API 추가:

```typescript
export const gsdApi = {
  // ... 기존 메서드

  // Task Execution
  planTask: (projectPath: string, phaseNumber: number) =>
    ipcRenderer.invoke('GSD_PLAN_TASK', projectPath, phaseNumber),

  researchTask: (projectPath: string, phaseNumber: number) =>
    ipcRenderer.invoke('GSD_RESEARCH_TASK', projectPath, phaseNumber),

  executeTask: (projectPath: string, planPath: string) =>
    ipcRenderer.invoke('GSD_EXECUTE_TASK', projectPath, planPath),

  cancelTask: (sessionId: string) =>
    ipcRenderer.invoke('GSD_CANCEL_TASK', sessionId),

  // Task Events
  onTaskOutput: (callback: (chunk: string) => void) => {
    const handler = (_: unknown, chunk: string) => callback(chunk);
    ipcRenderer.on('gsd:task:output', handler);
    return () => ipcRenderer.removeListener('gsd:task:output', handler);
  },

  onTaskComplete: (callback: (result: { success: boolean; planPath?: string }) => void) => {
    const handler = (_: unknown, result: any) => callback(result);
    ipcRenderer.on('gsd:task:complete', handler);
    return () => ipcRenderer.removeListener('gsd:task:complete', handler);
  },

  onTaskError: (callback: (error: string) => void) => {
    const handler = (_: unknown, error: string) => callback(error);
    ipcRenderer.on('gsd:task:error', handler);
    return () => ipcRenderer.removeListener('gsd:task:error', handler);
  }
};
```

**Acceptance**: API 정의, 이벤트 리스너 동작
