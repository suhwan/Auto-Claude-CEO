   ["기획", "분석", "리포트", "문서", "계약", "법률", "마케팅", "블로그",
    "SEO", "영업", "제안서", "견적", "회의", "조사", "연구"]

3. classify(request: str) -> RoutingResult:
   - 각 키워드 카테고리별 매칭 횟수 계산
   - coding_score > non_coding_score → CODING
   - non_coding_score > coding_score → NON_CODING
   - 둘 다 있으면 MIXED
   - confidence = abs(coding_score - non_coding_score) / max(total, 1)
   - keywords_matched 리스트 반환

4. is_coding_task(request: str) -> bool: 헬퍼 메서드

대소문자 무시, 정규식으로 단어 경계 매칭 (부분 매칭 방지)
