CEOIntegration 클래스 구현:

   - CEORouter, TeamRegistry 주입 또는 기본 생성

2. process_request(self, request: str) -> AgentResult:
   - router.route() 호출
   - target에 따라 분기:
     * "auto-claude" → AutoClaudeBridge로 위임 (이 Plan에서는 stub)
     * team 이름 → dispatch_to_team() 호출

3. dispatch_to_team(self, team_name: str, request: str) -> AgentResult:
   - TeamRegistry에서 Team 조회
   - Claude Code Task tool 호출 시뮬레이션
   - AgentResult 반환
   - 실제 Task tool 호출은 Claude Code 환경에서 실행

4. execute_team_task(self, team: Team, request: str) -> AgentResult:
   - 개별 팀 태스크 실행 로직
   - subagent_type = team.name
   - 현재는 시뮬레이션 결과 반환
